# خط عربي مخصص — التفعيل يدوي (خطوة واحدة بسيطة)

بيئتي هنا بلا اتصال إنترنت، فلم أستطع تنزيل ملفات الخط الفعلية (.ttf) لأدرجها معك.
الكود جاهز ومفعّل تلقائيًا بمجرد أن تضع الملفين هنا — **لا حاجة لتعديل أي كود إضافي**.

## لماذا لم أستخدم رابط خارجي (Google Fonts URL) بدلاً من ذلك؟
لأن تطبيقك **Offline-first** بالتصميم (موثّق في README الأصلي: الشبكة تُستخدم فقط
للتفعيل). تحميل خط من رابط خارجي عند كل تشغيل يتعارض مع هذا المبدأ ويكسر عمل
التطبيق بدون إنترنت. الحل الصحيح هو تضمين ملفات الخط محليًا هنا في `assets/fonts/`.

## الخطوات (5 دقائق)
1. اذهب إلى: https://fonts.google.com/specimen/IBM+Plex+Sans+Arabic
   (أو أي خط عربي حديث آخر تفضّله — Cairo وTajawal بدائل ممتازة أيضًا)
2. حمّل الخط، واستخرج (على الأقل) هذين الملفين:
   - `IBMPlexSansArabic-Regular.ttf`
   - `IBMPlexSansArabic-SemiBold.ttf`
3. ضعهما في هذا المجلد (`src/assets/fonts/`) بنفس الاسمين تمامًا.
4. شغّل التطبيق عاديًا (`flet run src/main.py`) — الخط سيُفعّل نفسه تلقائيًا.

## كيف يعمل التفعيل التلقائي
في `src/main.py` أضفت فحصًا يتحقق من وجود الملفين قبل استخدامهما:
```python
CUSTOM_FONTS = {
    "Plex": "fonts/IBMPlexSansArabic-Regular.ttf",
    "Plex SemiBold": "fonts/IBMPlexSansArabic-SemiBold.ttf",
}
```
- إن كانت الملفات **غير موجودة** (كحالك الآن): التطبيق يعمل بالضبط كما كان، بخط
  النظام الافتراضي، بدون أي تأثير أو خطر.
- إن كانت **موجودة**: تُفعَّل تلقائيًا كخط افتراضي لكل التطبيق.

هذا يعني أن هذا التعديل **صفر خطر** إلى أن تقرر إضافة الملفات بنفسك.
